what it is

A single static Go binary for provisioning numbers, wiring voice-agent applications, inspecting calls, sending messages, and asking Plivo's AI assistant when something looks off — all from the shell. Human-readable on a TTY, JSON-native when piped, with stable exit codes so scripts and AI driver loops can branch on them.

five-minute setup

From install
to your first
working call.

A typical first session: log in with your browser, verify, find and rent a number, point it at your application, place a test call, inspect what happened, and ask the AI for a sanity check.

total clicks · one
total passwords typed by the CLI · zero
1

Log in via your browser.

plivo login --browser

Loopback-OAuth (PKCE). Opens your default browser to Plivo Console; you click authorize; the token lands in your OS keychain. No password ever touches the CLI.

2

Confirm you're in.

plivo auth whoami

One round-trip to GET /Account/. Returns name, auth_id, billing mode, and credits. Table on a TTY, JSON when piped.

3

Find a number to rent.

plivo numbers search --country US --type local

Filters: country (required), type, region, pattern, limit. Read-only — no --yes needed.

4

Rent it. With --yes.

plivo numbers buy +1415… --yes

Spend verbs refuse without --yes — typed DESTRUCTIVE_REFUSED, exit code 5. Add --dry-run to preview the request.

5

Wire your application.

plivo account applications create --app-name "…" --answer-url https://…

Bundle your webhook URLs (answer · hangup · message) into an application. Numbers point at applications.

6

Attach the number.

plivo numbers update +1415… --app-id <uuid>

From this moment, inbound calls to that number hit your answer URL.

7

Test the wiring.

plivo voice calls make --from +1415… --to +91… --yes

Returns a call_uuid — you'll use it to inspect or diagnose what happens next.

8

Inspect.

plivo voice calls get <call_uuid>

Full record — direction, duration, hangup cause, cost. No console roundtrip.

9

Ask Buddy when something's off.

plivo voice calls diagnose <call_uuid>

Plivo's AI assistant pulls the SIP and media trace live and explains what happened, streamed token by token to your terminal.

plivo · ai assistant in the terminal

Ask the
assistant.

Plivo's AI assistant lives in the CLI too. Ask about docs, pricing, or error codes. Pass --call-uuid for live voice-debugger access — it pulls SIP and media traces and explains what happened. Tokens stream as they arrive.

plivo ask "…" — single-shot question
plivo ask --call-uuid <uuid> "…" — debug with live access
plivo voice calls diagnose <uuid> — shortcut
plivo messaging sms diagnose <uuid> — SMS debug
plivo support — past escalations
-o json — emits one JSONL event per SSE frame
